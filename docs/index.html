SCF APIv2026.2

The Secure Controls Framework as a validated, versioned, static JSON API — parsed from the official SCF workbook, gated on cross-sheet referential integrity, and rebuilt automatically on every upstream release. No auth, no rate limits, plain files.

Try it

# one control, with its framework crosswalks
curl -s https://sc2in.github.io/scf/api/controls/GOV-01.json | jq .title

# everything SCF maps to NIST SP 800-53 R5
curl -s https://sc2in.github.io/scf/api/crosswalks/general-nist-800-53-r5-2.json | jq .scf_to_framework

Endpoints

api/summary.jsonVersion, all counts, weight distribution.
api/controls.jsonAll controls with full metadata and crosswalks.
api/families.jsonFamily index.
api/crosswalks.jsonFramework index.
api/threats.jsonThreat catalog.
api/risks.jsonRisk catalog.
api/assessment-objectives.jsonAll assessment objectives.
api/evidence-requests.jsonEvidence request list.
api/compensating-controls.jsonCompensating control guidance.
api/privacy-principles.jsonData privacy management principles.
